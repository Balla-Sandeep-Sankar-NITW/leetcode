
# 🎯 Grindlist — Company-wise LeetCode Tracker

Grindlist is a lightweight, single-page web dashboard designed to help software engineers track and organize LeetCode problems by target company. Progress is saved locally in your browser and synced across all company lists sharing the same problem ID.

## 🔗 Access Grindlist

* **Live Web App:** [Launch Grindlist](https://www.google.com/search?q=https://your-username.github.io/grindlist)
* **Data Source:** [snehasishroy/leetcode-companywise-interview-questions](https://github.com/snehasishroy/leetcode-companywise-interview-questions)

---

## ✨ Features

* **650+ Companies:** Dedicated problem lists for major tech companies.
* **Cross-Sync:** Mark a problem as solved once, and it checks off across all company lists containing it.
* **100% Client-Side Privacy:** Progress is saved in browser `localStorage` — no sign-ups or servers required.
* **Filter & Sort:** Filter by difficulty (*Easy*, *Medium*, *Hard*) or sort by frequency and acceptance rate.
* **Pinning:** Keep your top target companies pinned to the top of the sidebar.
* **Import/Export:** Backup and transfer your progress using JSON files.
